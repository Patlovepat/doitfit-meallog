ทำไมต้อง Log?

การบันทึกอาหารทุกมื้อช่วยให้เห็น ว่ากินอะไรไปจริงๆ ไม่ใช่แค่เดา ข้อมูลนี้ทำให้โค้ชช่วยได้ตรงจุด และตัวเองก็รู้ว่าต้องปรับอะไรในมื้อถัดไป

😕
ไม่ Track
เดาว่ากินพอ · ไม่รู้ว่าขาดโปรตีน · โค้ชช่วยได้น้อยเพราะไม่มีข้อมูล
💪
Track ทุกมื้อ
รู้ทันทีว่าเหลืออีกเท่าไหร่ · โค้ชเห็นปัญหาและแนะนำได้ตรง
📊 สิ่งที่แอปติดตามให้
Macro คืออะไร?
C · P · F ย่อมาจาก Macronutrient — สารอาหารหลัก 3 ตัวที่ร่างกายต้องการในปริมาณมากทุกวัน ทุกอาหารที่กินเข้าไปมีส่วนผสมของ 3 ตัวนี้ในสัดส่วนต่างกัน แอปจะรวมให้อัตโนมัติ
🟠 Carb (C) = คาร์โบไฮเดรต — พลังงานหลัก ใช้ก่อนเสมอ
🔵 Protein (P) = โปรตีน — ซ่อมแซมและสร้างกล้ามเนื้อ
🟣 Fat (F) = ไขมัน — ฮอร์โมนและพลังงานสำรอง
⚡ kcal = พลังงานรวม คำนวณจาก C×4 + P×4 + F×9
💡 โค้ชตั้ง เป้าหมาย C/P/F ไว้ให้แล้วตามแผนของแต่ละคน ไม่ต้องคำนวณเอง แค่บันทึกครบ ระบบเปรียบเทียบให้อัตโนมัติ

วิธี Log ทำยังไง?

แอปมี 3 โหมด เลือกตามสถานการณ์ ไม่ต้องใช้ทุกโหมดทุกมื้อ

👊
Hand Mode
เลือกอาหารเป็นสัดส่วนมือ — เร็วที่สุด ใช้บ่อยที่สุด
✅ ใช้เมื่อ: กินอาหารบ้าน · กะด้วยสายตา · อยากบันทึกเร็ว
✍️
กรอก Mode
กรอกปริมาณเป็นกรัมหรือหน่วยโดยตรง — ไม่มี AI ตัวเลขที่ใส่ = ตัวเลขที่บันทึก
✅ ใช้เมื่อ: มีฉลากโภชนาการ · ชั่งน้ำหนักอาหารแล้ว · รู้กรัมแน่ๆ
✨
AI Mode
พิมพ์บอกว่ากินอะไรบ้าง — AI แปลงเป็น macro ให้ · แก้ปริมาณได้ก่อนบันทึก · ไม่มีถ่ายรูป
✅ ใช้เมื่อ: กินนอกบ้าน · ทำอาหารเอง · ไม่รู้กรัมแน่ๆ
💡 90% ของมื้อ ใช้ Hand Mode ได้เลย เร็วที่สุด · ใช้ AI Mode เมื่อกินนอกบ้านและอยากพิมพ์บอก AI · ใช้กรอก Mode เมื่อรู้กรัมแน่ๆ และไม่ต้องการให้ AI เดา

คำถามที่พบบ่อย
Q
ลืม Log มื้อเมื่อกี้ แก้ยังไง?
แอปรองรับครับ — แถบวันที่ด้านบนหน้า Log จะแสดง 7 วันย้อนหลัง ให้แตะเลือก แล้ว Log ได้เลย · ไม่ต้องรีบกรอกทันทีหลังกิน
Q
ตัวเลข C / P / F หน่วยคืออะไร?
C = Carbohydrate (คาร์บ) · P = Protein (โปรตีน) · F = Fat (ไขมัน) · หน่วยทั้งหมดคือ กรัม (g) · kcal คือพลังงานรวม
Q
AI Mode วิเคราะห์ผิด ทำยังไง?
แก้ ปริมาณ ของแต่ละรายการได้ทันทีในหน้าผล AI ก่อนกด "บันทึก" · ถ้าไม่แน่ใจให้ประมาณให้ใกล้เคียงที่สุด
Q
โค้ชเห็นข้อมูลที่ Log ไหม?
เห็นทุกอย่างที่บันทึก — มื้ออาหาร · สรุปประจำวัน · Health Log · แผนอาหาร · ไม่ต้องส่งแยกหรือแจ้งโค้ชเพิ่ม
Q
ต้อง Log ครบทุกมื้อไหม?
ไม่บังคับ แต่ยิ่ง Log ครบยิ่งดี เพราะโค้ชจะเห็นภาพรวมและแนะนำได้ตรงกว่า · ถ้าลืมมื้อไหนก็ไม่เป็นไร Log ต่อได้เลย
Q
Health Log บันทึกอะไรบ้าง?
ชั่วโมงนอน · จำนวนก้าว · อารมณ์/ความรู้สึก
น้ำหนักและสัดส่วน — ชั่งตอนเช้าก่อนกินหรือดื่มอะไร ค่าจะแม่นที่สุด เพราะไม่มีน้ำหนักอาหารหรือความบวมมาบวก · แนะนำอาทิตย์ละครั้ง
